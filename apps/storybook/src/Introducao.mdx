# Maestro

Biblioteca de componentes e design system da BigBrain, construída com React, TypeScript, Tailwind CSS v4 e shadcn/ui.

## Como navegar

- **Fundamentos:** tokens de design (cores, raios, tipografia).
- **UI:** componentes atômicos (Button, Input...).
- **Componentes:** componentes compostos, montados a partir dos atômicos.

Use o seletor de tema na barra superior para alternar entre claro e escuro, e a aba **Accessibility** para ver a auditoria de cada story.
